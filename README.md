1. [Задание 1.](./docs/zadanie1.md)
Сформировать команду, которая выводит список процессов, сортирует по CPU, сохраняет результат в файл, ошибки не попадают в файл. Отдельно продемонстрировать работу с ошибкой (например, неправильно написать в команде утилиту, которая выводит список процессов) и корректную работу. 

2. [Задание 2.](./docs/zadanie2.md)
Написать команду, которая выводит топ 10 процессов от текущего пользователя и при этом выводит результат одновременно в терминал и в файл (запись в файл, а потом его чтение не считается). 

3. [Задание 3.](./docs/zadanie3.md)
Просканировать ресурс scanme.nmap.org, проверить, какие порты открыты (задать порты разными способами: перечислением, диапазоном, и.т.п.), какие на них запущены сервисы, какая ОС установлена, а также отдельной командой просканировать только порты и вывести результат в grepable формате в Терминал (запись в файл, а потом его чтение не считается). 

4. [Задание 4.](./docs/zadanie4.md)
Нужно сделать такой скрипт или обертку nmap, чтобы передавались в него те же самые параметры, что и для nmap (детект сервисов, детект ОС, указание портов разными способами, передача целей для сканирования (из файла или в строке запуска)), чтобы результат сканирования выводился в файл в формате json.  
При этом в json отчете не должно быть лишних полей, то есть, если не передавался параметр для детектирования ОС, то ключа, связанного с ОС в json быть не должно, аналогично с детектом сервисов. 
Желательно на Python или Bash. Если очень хочется, то можно и на компилируемом языке, но тогда в репу кладите бинарь, который скомпилирован на ВМ в Kali.
